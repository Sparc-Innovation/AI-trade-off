# AI Compliance Trade-Off LMS

This project is an interactive Learning Management System (LMS) focused on AI Compliance.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Recommended version 18+)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Sparc-Innovation/AI-trade-off.git
   ```
2. Navigate to the project directory:
   ```bash
   cd AI-trade-off
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the development server:
```bash
npm run dev
```
The app will be available at the URL provided in the terminal (usually `http://localhost:5173`).

## Project Structure
- `index.html`: Main entry point.
- `main.js`: Core application logic.
- `style.css`: Main styling.
- `courseData.js`: Content and course structure.
- `firebase-config.js`: Firebase configuration.

## Collaboration
- Please create a new branch for any fixes or features.
- Ensure you run `npm run build` to verify the build process before pushing major changes.
